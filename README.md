# Графік відключень світла — Telegram Mini App

Один файл `index.html`, без збірки й без сервера. Показує:

- поточний стан («Світло є / немає») і час до зміни;
- шкалу по півгодинах на сьогодні й завтра з маркером «зараз» та списком відключень;
- порівняння всіх черг за годинами без світла (торкніться стовпчика, щоб обрати чергу);
- типовий тиждень (шаблон оператора) для обраної черги.

Регіони: Київ, Київщина, Одещина, Дніпро (ДТЕК). Вибір регіону й черги запам'ятовується
(Telegram CloudStorage, запасний варіант — localStorage). Тема береться з Telegram, тож
працюють світла й темна.

## Дані

Графіки читаються прямо з браузера з відкритого дзеркала
[Baskerville42/outage-data-ua](https://github.com/Baskerville42/outage-data-ua)
(`raw.githubusercontent.com`, CORS `*`, оновлення ~кожні 5 хв). Формат описано в
[fastiuk/ukraine-energy-monitor → docs/SOURCES.md](https://github.com/fastiuk/ukraine-energy-monitor/blob/main/docs/SOURCES.md).
Інші області (ЛОЕ, YASNO тощо) цей застосунок не показує: їхні API або не віддають CORS, або
вимагають серверного проксі — див. «Розширення».

## Запуск за 5 хвилин

1. Створіть репозиторій на GitHub і покладіть туди ці файли (`index.html`, `.github/workflows/pages.yml`).
2. **Settings → Pages → Source: GitHub Actions.** Після першого пуша в `main` сторінка буде за адресою
   `https://<user>.github.io/<repo>/` (потрібен HTTPS — Pages його дає).
3. У [@BotFather](https://t.me/BotFather):
   - `/newbot` — створіть бота (якщо ще немає);
   - `/newapp` — оберіть бота, вкажіть назву, опис і URL зі сторінки Pages, short name, наприклад `grafik`;
   - або `/setmenubutton` — щоб застосунок відкривався кнопкою меню бота.
4. Посилання на застосунок: `https://t.me/<bot_username>/grafik`.

### Глибокі посилання

`https://t.me/<bot_username>/grafik?startapp=kyiv_19-1` — відкриє Київ, черга 19.1
(формат `регіон_номер-підчерга`; регіони: `kyiv`, `kyiv-region`, `odesa`, `dnipro`).
Можна розсилати людям їхню чергу готовим посиланням.

### Перевірка у браузері

Відкрийте `index.html` або сторінку Pages у звичайному браузері — працює і без Telegram.
Параметри для тесту: `?r=odesa&g=2.1`.

## Розширення

- Інші області/оператори — потрібен невеликий бекенд-проксі (Cloudflare Worker тощо) на базі
  бібліотеки `ua_outages` з репозиторію ukraine-energy-monitor, який віддає той самий JSON-формат
  (`fact.data[unix_північ][GPV<черга>][година]`); тоді достатньо додати рядок у `REGIONS` та змінити `DATA_URL`.
- Пошук черги за адресою — теж через проксі до API оператора.
- Сповіщення «за 30 хв до відключення» — окремий бот, що читає ті самі JSON.

## Застереження

Неофіційний застосунок. Графіки можуть змінюватися, особливо в разі аварійних відключень.
